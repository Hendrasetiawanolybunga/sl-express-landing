# PT. Smail Logistik Express (SL Express) - Landing Page

Official production-ready, highly responsive, high-converting logistics landing page for **PT. Smail Logistik Express (SL Express)** — *"Selalu Sampai, Selalu Aman"*.

Spesialis pengiriman kargo laut, kapal Pelni, dan angkutan darat (trucking) dari Jakarta ke seluruh Kepulauan Riau (Batam, Tg. Pinang, Tg. Balai Karimun, Natuna, Anambas, Lingga) serta kota-kota besar di Indonesia.

---

## 🚀 Fitur Utama & Keunggulan
- **60-30-10 Design System:** Tampilan modern, bersih, profesional, dan berorientasi konversi tinggi.
- **Kalkulator Simulasi Biaya Kargo Instan:** Memungkinkan calon klien menghitung estimasi biaya dan langsung memesan via WhatsApp dengan pesan otomatis terisi.
- **Tabel Tarif & Rute Interaktif (Real-time Filter & Search):** Pencarian instan nama kota (Batam, Pekanbaru, Medan, Lampung, dsb) serta filter kategori wilayah.
- **Sorotan Khusus Rute Kepulauan Riau (FTZ Batam, Pelni & Cargo):** Edukasi komprehensif penanganan kargo laut dan kepabeanan Batam / Kepri.
- **FAQ Accordion & 4 Langkah Kirim Kargo:** Membangun kepercayaan pelanggan dan menjawab pertanyaan krusial pengiriman kargo.
- **Floating WhatsApp Action Button (FAB) & Back to Top:** Pulsing effect untuk mendongkrak konversi chat ke admin (08111319553).
- **Zero Framework Dependency:** Murni HTML5 semantik, CSS3 modern, dan Vanilla JavaScript ES6+.
- **Vercel Ready:** Siap di-deploy secara instan ke Vercel dengan optimasi header keamanan & caching.

## 📁 Struktur Direktori
```text

│   ├── logo.png     # Logo resmi SL Express
│   └── logo.jpeg    # Logo fallback

```

---

## 🚢 Deploy ke Vercel
1. Hubungkan repositori GitHub/GitLab ke [Vercel](https://vercel.com).
2. Pilih direktori `ekspedisi`.
3. Klik **Deploy** (Pengaturan framework: `Other` / Static).
4. Selesai! Website live dalam hitungan detik.
